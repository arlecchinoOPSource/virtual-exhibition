# Security and privacy

The project serves static client-side assets. Treat every committed path and its Git history as public. Review essay content and asset metadata before committing. The project does not collect visitor data or include tracking. Audio requires a visitor gesture.

Report vulnerabilities privately through the repository's Security reporting feature if enabled, or contact the maintainer privately through an existing channel. Include the affected commit or version, impact, and reproduction details. Use public issues for ordinary bugs and omit sensitive information.
